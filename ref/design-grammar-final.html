1. 결론

목표는 ‘복고풍으로 새로 디자인한 웹사이트’가 아니라, 한 개인이나 작은 지역 공동체가 2000년대 초부터 직접 운영해 온 홈페이지입니다.

Riddersholm = 골격

왼쪽 메뉴, 상단 제목, 긴 본문, 작은 사진, 뉴스와 개인 기록이 한 페이지에 공존하는 전체 구조.

2004년 홈페이지 열기

Sundet = 강조 페이지

강한 배경색, 가운데 정렬, GIF 장식, 큰 링크, 연도별 방명록과 운영자의 직접적인 말투.

방명록 열기
조합 원칙

전체 사이트는 Riddersholm의 골격을 사용하고, 방명록·회원 모집·행사 특집 같은 일부 페이지에 Sundet의 강한 색과 중앙 정렬을 적용합니다. 후순위 일곱 곳에서는 카누 클럽의 실제 운영 정보만 선별합니다.

2. 레퍼런스 위계

모든 레퍼런스를 같은 비중으로 섞지 않습니다. 외형을 정하는 사이트와 기능을 빌리는 사이트를 분리합니다.

이 홈페이지는 카누를 좋아하는 지역 사람들의 모임과 사진, 기록을 가족과 친구들에게 소개하기 위해 만들었습니다.

최근 소식

▪ 오래된 회원 사진을 찾습니다
▪ 초보 회원의 첫 카누 이야기
▪ 중고 패들 한 자루 나눔

우리 모임은

매달 둘째 주 토요일에 강가에서 만나 함께 노를 젓습니다. 더 자세한 이야기는 여기에서 볼 수 있습니다.

  1. 메뉴가 별도 오브젝트처럼 보입니다. 같은 크기의 이미지 버튼이 홈페이지의 목차가 됩니다.
  2. 첫 화면이 전체 사이트의 축약본입니다. 소개·뉴스·사람·장소·사진을 세로로 계속 보여줍니다.
  3. 사진은 장식보다 증거입니다. 실제 사건과 인물을 확인시키는 작은 기록 사진입니다.
  4. 운영자가 숨지 않습니다. 이름, 사이트 목적, 연락 방식과 개인적인 인사를 직접 남깁니다.

5. Sundet Guestbook의 문법

측정된 핵심: Times 16px, 흰 본문, 흰 링크와 노란 방문 링크, 빨간 대형 제목, 62×61px 캐릭터 GIF, 640×10px 도로 GIF 구분선, 두 개의 <center> 영역.

방명록 — “THE GUESTBOOK”

방명록에 쓰기
방명록 읽기

1996, 1997, 1998, 1999, 2000, 2001, 2002, 2003, 2004

처음 오셨나요? 어렵지 않습니다!

이름과 짧은 인사를 남겨 주세요. 지난 모임에서 찍은 사진이 있다면 사진첩 담당자에게 보내 주셔도 좋습니다.
  1. 대칭과 반복이 그리드를 대신합니다. 거의 모든 것이 가운데 정렬됩니다.
  2. 방문 여부가 색으로 보입니다. 링크의 상태 변화가 사용자의 흔적이 됩니다.
  3. GIF가 로고와 구분선 역할을 합니다. 작은 그림도 화면 구조에 적극적으로 참여합니다.
  4. 연도 목록이 곧 역사입니다. 오래된 기록을 첫 화면에서 숨기지 않습니다.

레이아웃과 정보

  • 페이지는 위에서 아래로 길게 읽으며 첫 화면에도 정보가 많습니다.
  • 카드 대신 제목, 수평선, 이미지, 빈 줄로 내용을 구분합니다.
  • 본문은 15~17px 세리프, 소제목은 22~26px, 모든 링크에는 밑줄을 둡니다.
  • 사진은 같은 비율로 자르지 않고 140px, 220px, 320px 등 서로 다른 크기로 둡니다.
  • 구체적인 날짜, 장소, 이름과 작은 사건을 기록합니다.
  • 과거 소식과 사진을 삭제하지 않고 연도별로 쌓습니다.

카누 클럽 운영 문법

  • 방문자별 묶음: 회원, 가입 희망자, 초보자의 링크를 분리합니다.
  • 날짜 우선 일정: 날짜, 행사명, 시간, 참가 인원을 한 줄에서 확인하게 합니다.
  • 계절 안전 공지: 구명조끼 기간, 수온, 동행 규칙을 홈에 반복 노출합니다.
  • 문서 저장소: 회보, 회의록, 회칙, 가입서와 연간 계획 PDF를 보존합니다.
  • 담당자가 보이는 안내: 강습·사진·장비 담당자의 이름과 연락 경로를 둡니다.
  • 생활형 기록: 장비 분실물, 선착장 청소, 함께 탈 사람과 중고 장비도 기록합니다.

7. 카누 클럽 페이지 구조

홈은 Dömitz처럼 왼쪽 메뉴·중앙 본문·오른쪽 일정의 3열을 사용하고, 서브페이지는 Riddersholm처럼 왼쪽 메뉴와 긴 본문의 2열로 단순화합니다.

  1. 작은 카누 GIF 또는 저해상도 로고사이트의 수작업 감각을 처음부터 드러냅니다.
  2. 텍스트 배너한국 아마추어 카누 클럽이라는 이름을 장식보다 먼저 보여줍니다.
  3. 운영자 소개홈페이지를 만든 이유와 웹마스터의 짧은 서명을 둡니다.
  4. 최근 소식 5~7개정기 패들, 장비 나눔, 사진 요청처럼 실제적인 소식을 나열합니다.
  5. 다음 일정과 안전 공지오른쪽 좁은 칸에 날짜와 구명조끼·수온 정보를 둡니다.
  6. 회원·초보자 자료회보, 가입서, 강습 상태와 비용을 방문자별로 묶습니다.
  7. 지역 수로와 사진첩강·호수·선착장 정보와 연도별 활동 기록을 연결합니다.
  8. 방명록과 상태 줄개설일, 마지막 수정일, 방문자 수와 웹마스터를 함께 적습니다.

8. 구현 경계

사용하지 않을 것

  • 둥근 카드와 부드러운 그림자
  • 화면 전체 히어로 이미지
  • 균일한 3열 상품형 그리드
  • 햄버거 메뉴와 아이콘 전용 메뉴
  • 모든 사진의 강제 동일 비율
  • 짧고 추상적인 광고 문구
  • GLX·NORD식 SNS 카드와 반응 버튼

현대적으로 지킬 것

  • 표 대신 의미 있는 HTML과 CSS 사용
  • 키보드 포커스와 대체 텍스트 제공
  • 배경 이미지 없이도 읽히는 대비
  • 모바일에서는 메뉴를 2열로 펼쳐 표시
  • 방문 링크 색의 접근성 확인
  • 사진마다 촬영연도와 설명 기록

  • 링크가 밑줄과 상태색을 갖는가?
