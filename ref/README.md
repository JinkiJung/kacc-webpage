# 레퍼런스 조사 노트

이 폴더는 `한국 아마추어 카누 클럽` 프론트엔드의 시각·정보 구조를 설계하기 위한 참고 자료 모음이다.

- 조사일: 2026-10-04
- 범위: 한국과 북유럽·독일권의 아마추어 협회, 수상 스포츠 동호회, 개인 홈페이지, 외딴 지역 포털, 취미 사이트와 소규모 상점
- 선정 기준: 오래된 동호회 홈페이지 분위기, 풍부한 메뉴, 행사와 공지, 사진 기록, 달력, 회원 중심 정보, 수작업한 듯한 레이아웃
- 주의: 원본의 이미지나 문구를 복제하기 위한 목록이 아니다. 공통된 정보 구조와 디자인 문법을 분석하기 위한 자료다.

## 현재 가장 중요한 레퍼런스

1. 한국아마추어무선연맹 — 복잡한 협회형 정보 구조
2. KSV Lok Riesa — 실제 2003년식 구형 웹 문법
3. Esrum Sø — 지역 수상활동 링크 허브와 기상정보
4. Sørup Havns Bådelav — 사진·회원회보·행사 중심의 생활형 동호회
5. Oxelösunds Kanotklubb 1997 페이지 — 초기 웹의 링크·메뉴·인코딩 감성
6. Kano.no — 카누 제품과 자연 이미지를 결합한 오래된 노르웨이형 페이지
7. Webhistorie.dk — 방문자 수·방명록·마지막 업데이트가 살아 있는 초기 웹 문법
8. Höljäkkä — 지역 행사와 생활정보가 한데 모인 외딴 마을형 홈페이지
9. Sundet TruckStop — 1996년부터 쌓인 실제 취미 방명록
10. Godstoget Hobby — 수동 결제·픽업 안내가 강한 생활형 취미 상점
