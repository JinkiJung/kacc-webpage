# 한국 아마추어 카누 클럽 — 최종 디자인 문법 조사

- 작성일: 2026-10-04
- 최종 기준 사이트:
  1. [Carsten Riddersholm Home (2004)](https://www.riddersholm.dk/crhome/)
  2. [Sundet TruckStop Guestbook](https://www.sundet.no/gbok.htm)
- 후순위 레퍼런스: Dömitz, Riesa, PALO, Esrum Sø, GLX, NORD, Pilen
- 제외 방향: 현대적인 카드 UI, 큰 히어로 이미지, 넓은 여백, 둥근 모서리, 앱처럼 정돈된 대시보드

## 1. 결론

원하는 결과는 ‘복고풍으로 새로 디자인한 사이트’가 아니라 **한 개인이나 작은 지역 공동체가 2000년대 초부터 직접 운영해 온 홈페이지**다.

두 핵심 레퍼런스가 담당할 역할은 다음과 같다.

- **Riddersholm:** 전체 사이트의 골격. 왼쪽 메뉴, 상단 제목, 긴 본문, 작은 사진, 소식과 가족·지역 기록이 한 페이지에 공존하는 방식.
- **Sundet:** 강조 페이지의 성격. 강한 배경색, 가운데 정렬, GIF 장식, 큰 링크, 연도별 방명록과 운영자의 직접적인 말투.

따라서 카누 클럽 사이트는 Riddersholm을 기본 뼈대로 삼고, 방명록·행사 특집·회원 모집 같은 일부 페이지에 Sundet의 강한 색과 중앙 정렬을 사용한다. 후순위 일곱 곳은 이 뼈대를 바꾸기보다 카누 클럽에 필요한 실제 운영 정보와 보조 레이아웃을 채우는 데 사용한다.

## 2. 레퍼런스 위계

### 1순위 — 전체 인상을 결정

- [Riddersholm](https://www.riddersholm.dk/crhome/) — 사이트 셸, 왼쪽 메뉴, 긴 첫 화면, 개인적인 기록 방식
- [Sundet Guestbook](https://www.sundet.no/gbok.htm) — 방명록·특집 화면, 중앙 정렬, GIF 구분선, 강한 상태색

### 2순위 A — 시각 문법도 직접 반영

- [Dömitzer Kanu Verein](https://www.kanu-doemitz.de/) — 사진 배너 아래 `왼쪽 일정 / 중앙 소개·자료 / 오른쪽 뉴스`의 3열 홈. 붉은 제목 바와 조밀한 실무 정보가 좋다.
- [KSV Lok Riesa](https://kanu-riesa.lima-city.de/startseite.htm) — 큰 사진을 두 장씩 나열하는 활동 기록, 단순한 흰 배경, 개설일·마지막 관리일, 솔직한 개인정보 문구가 좋다.

### 2순위 B — 외형보다 기능과 콘텐츠를 반영

## 4. Riddersholm 문법

### 실제 관찰값

- 배경: `_themes/edge/edgbkgnd.gif` 타일 이미지 위 흰색 계열
- 기본 글꼴: `Times`, 콘텐츠는 주로 `Georgia, Times New Roman, Times`
- 링크: `#009933`, 방문한 링크 `#996633`, 활성 링크 `#666699`
- 메뉴 버튼: 폭 140px, 높이 34px의 개별 GIF 이미지
- 본문 제목: 약 24px, 진한 녹색 `#006633`
- 서명·주소: Comic Sans MS
- 레이아웃: 폭 100% 표 여러 개로 열과 콘텐츠를 구성
- 이미지: 서로 다른 크기와 화질의 실제 사진, 클립아트, 15×15px 불릿 GIF
- 하단: 사이트 최초 개설일, 방문자 카운터, 저작권 연도

### 화면 골격

```text
┌──────────────┬──────────────────────────────────────────────┐
│ 작은 로고    │              사이트 이름 배너               │
├──────────────┼──────────────────────────────────────────────┤
│ 시작         │ 큰 환영 제목                     운영자 사진│
│ 소식         │ 소개문·운영 목적·서명                       │
│ 회원 소개    │                                              │
│ 클럽 역사    │ 작은 삽화   최근 소식과 밑줄 링크 목록       │
│ 카누 활동    │                                              │
│ 사진         │ 회원 사진   추모·회원 소개                   │
│ 방명록       │                                              │
│ 링크         │ 제목 + 긴 문단 + ‘더 보기’의 반복           │
└──────────────┴──────────────────────────────────────────────┘
```

### 중요한 특징

1. **메뉴가 별도 오브젝트처럼 보인다.** 모든 메뉴가 같은 높이의 이미지 버튼이며 본문과 뚜렷이 분리된다.
2. **첫 화면이 사이트 전체의 축약본이다.** 소개, 최근 소식, 인물, 집, 여행, 사진, 링크의 미리보기가 세로로 계속 이어진다.
3. **사진은 장식보다 증거다.** 고화질 화보가 아니라 실제 사람과 사건을 확인시켜 주는 작은 기록 사진이다.
4. **정보 위계가 단순하다.** 큰 녹색 제목, 검은 본문, 초록 밑줄 링크 세 단계만 반복한다.
5. **운영자 존재가 노출된다.** 이름, 주소, 사이트 목적, 삭제 요청 연락법까지 직접 적는다.

## 5. Sundet Guestbook 문법

### 실제 관찰값

- 배경: `bak14.gif` 파란색 타일 이미지
- 본문 글자: 흰색
- 기본 링크: 흰색, 방문한 링크: 노란색 `#FFFF00`
- 기본 글꼴: 브라우저 기본 `Times`, 본문 16px
- 제목: 빨간색 `<font size="9">`; 브라우저에 따라 약 40px 이상
- 주요 링크: 24px 굵은 밑줄
- 연도 아카이브: 약 18.7px 굵은 밑줄 링크가 한 줄에 연결
- 구분선: 폭 640px, 높이 10px의 `road.gif`
- 캐릭터: 62×61px `devil01.gif`
- 구조: `<center>`, `<font>`, `<h2>`, `<h3>` 중심의 단순 HTML
- 콘텐츠: 방명록 쓰기/읽기, 1996~2004 아카이브, 영어 번역, 농담, 이전 페이지 링크

### 화면 골격

```text
          [작은 GIF]  방명록 - THE GUESTBOOK
          ==================================

                   방명록 쓰기
                   방명록 읽기

       1996, 1997, 1998 ... 2003, 2004
       ==================================

             외국 방문자를 위한 설명
       이름 / 이메일 / 홈페이지 / 사진 URL
                 직접적인 사용법

             “쉽지요? 할 수 있습니다!”

                방명록에 이름 남기기
                방명록 구경하기
       ==================================
                 메인 페이지로 돌아가기
```

### 중요한 특징

1. **거의 모든 것이 가운데 정렬되어 있다.** 정교한 그리드 대신 대칭과 반복으로 질서를 만든다.
2. **방문 여부가 색으로 보인다.** 흰 링크가 클릭 후 노란색으로 바뀌어 사용자의 흔적을 남긴다.
3. **GIF가 구조물 역할을 한다.** 캐릭터는 로고, 도로 그림은 수평선이 된다.
4. **연도 목록이 곧 사이트의 역사다.** 오래된 기록을 숨기지 않고 첫 화면에서 가장 잘 보이게 한다.
5. **운영자의 농담이 인터페이스 문구가 된다.** 설명문이 정중한 제품 문구가 아니라 사람의 말처럼 들린다.

## 6. 통합 문법

### 6.1 레이아웃

- 페이지는 위에서 아래로 길게 읽힌다.
- 첫 화면 하나에 소개, 최신 소식, 기록과 링크를 많이 노출한다.
- 정보는 카드가 아니라 제목, 수평선, 이미지, 빈 줄로 나눈다.
- 정렬은 완벽하지 않아도 되지만 메뉴와 본문의 큰 축은 일정해야 한다.
- 모바일 앱 같은 하단 메뉴나 햄버거 메뉴는 사용하지 않는다.

### 6.2 타이포그래피

- 기본은 Georgia, Times New Roman, Times와 같은 세리프 계열.
- 본문 15~17px, 메뉴 13~15px, 소제목 22~26px.
- 링크에는 항상 밑줄을 남긴다.
- 제목에는 녹색, 빨강처럼 분명한 한 가지 색을 사용한다.
- 일부 서명이나 짧은 인사에만 Comic Sans 계열을 제한적으로 쓸 수 있다.

### 6.3 색과 질감

기본 페이지:

- 배경: `#F4F1DF` 또는 작은 종이색 타일
- 본문: `#111111`
- 제목: `#006633`
- 링크: `#009933`
- 방문 링크: `#996633`
- 가는 선: `#C9B568`

방명록·특집 페이지:

- 배경: `#071064`에서 `#173DCE` 사이의 파란 타일
- 본문과 기본 링크: `#FFFFFF`
- 방문 링크: `#FFFF00`
- 큰 제목: `#F44336`
- 구분선: 검정·노랑 또는 카누 패들 모티프 GIF

### 6.4 이미지

- 동일 비율의 카드 썸네일을 만들지 않는다.
- 사진 폭은 140px, 220px, 320px처럼 상황에 따라 다르게 쓴다.
- 회원이 직접 찍은 사진, 오래된 행사 사진, 장비 사진을 우선한다.
- 작은 GIF 아이콘과 불릿을 반복 사용한다.
- 이미지에는 얇은 테두리만 사용하고 그림자·둥근 모서리는 쓰지 않는다.

### 6.5 콘텐츠와 말투

- ‘브랜드 소개’보다 ‘이 홈페이지를 만든 이유’를 쓴다.
- 회장 또는 웹마스터가 직접 말하는 1인칭 문장을 사용한다.
- 구체적인 날짜, 장소, 이름과 작은 사건을 남긴다.
- 과거 공지와 사진을 삭제하지 않고 연도별로 축적한다.
- 링크 이름은 `자세히 보기`보다 `2004년 봄 한강 패들 사진 보기`처럼 구체적으로 쓴다.

### 6.6 후순위 레퍼런스에서 추가된 운영 문법

- **방문자별 정보 분리:** 회원, 가입 희망자, 초보자에게 필요한 링크를 각각 묶는다. Dömitz 방식이 가장 직접적이다.
- **날짜 우선 일정:** 날짜를 먼저 굵게 표시하고 행사명, 시간, 참가자 수를 뒤에 붙인다.
- **계절 안전 공지:** 구명조끼 착용 기간, 수온, 연안 운항, 초보자 동행 규칙을 홈에 반복 노출한다.
- **문서 저장소:** 회보, 회의록, 회칙, 가입서, 연간 계획은 PDF 원문 링크로 보존한다.
- **사람이 보이는 담당 체계:** `강습 담당자`, `사진 담당자`, `장비 담당자`처럼 이름과 연락 경로를 표시한다.
- **클럽의 잡무도 기록:** 선착장 청소, 장비 분실물, 깃발 수리, 클럽하우스 작업일을 공식 활동과 같은 위계로 다룬다.
- **강습의 현재 상태:** 모집 예정, 마감, 잔여석, 비용과 신청 방법을 한곳에서 확인하게 한다.
- **회원 게시판:** 물건 찾기, 함께 탈 사람 모집, 중고 장비와 행사 음식 준비 같은 생활형 게시물을 둔다.

## 7. 이 프로젝트의 페이지 구조

### 공통 셸

```text
사이트 폭: 약 980~1100px
왼쪽 메뉴: 150px
메뉴와 본문 사이: 20~28px
본문: 나머지 폭
홈 오른쪽 소식 칸: 200~230px
기본 배치: 중앙 정렬 또는 화면 왼쪽에서 8~16px 여백
```

### 첫 화면 순서

1. 작은 카누 GIF 또는 저해상도 로고
2. `한국 아마추어 카누 클럽` 텍스트 배너
3. 왼쪽 이미지형 메뉴
4. `우리 홈페이지에 오신 것을 환영합니다` 소개와 운영자 서명
5. 최근 소식 5~7개
6. 오른쪽 좁은 칸에 다음 일정과 계절 안전 공지
7. 회원·가입 희망자·초보자용 자료 묶음
8. 회원 또는 운영진 사진과 짧은 소개

### 첫 화면 열 구성

```text
┌──────────────┬──────────────────────────┬──────────────────┐
│ 이미지 메뉴  │ 환영 인사·최근 활동      │ 다음 일정        │
│ 클럽 링크    │ 큰 기록 사진과 설명      │ 안전 공지        │
│ 관련 단체    │ 회원/초보자 자료 링크    │ 최근 소식        │
└──────────────┴──────────────────────────┴──────────────────┘
```

서브페이지에서는 오른쪽 칸을 제거하고 Riddersholm처럼 왼쪽 메뉴와 긴 본문만 사용한다.

## 8. 사용하면 안 되는 현대적 문법

- 둥근 카드와 부드러운 그림자
- 화면 전체를 덮는 히어로 이미지
- 균일한 3열 상품형 그리드
- 아이콘만 있는 메뉴
- 과도한 애니메이션과 스크롤 효과
- 그라데이션 버튼과 유리 효과
- 모든 사진을 같은 비율로 자르는 처리
- 짧고 추상적인 광고 문구
- 정보량을 줄이기 위한 과도한 접기와 숨김

## 9. 기술 구현 원칙

옛 HTML의 외관은 가져오되 문제점은 재현하지 않는다.

- `<table>`, `<center>`, `<font>` 대신 CSS Grid/Flex와 의미 있는 HTML을 사용한다.
- 이미지 메뉴에도 실제 텍스트와 키보드 포커스를 제공한다.
- 배경 GIF가 없어도 내용을 읽을 수 있게 대비를 확보한다.
- 모바일에서는 왼쪽 메뉴를 화면 위의 2열 텍스트 메뉴로 바꾸되 햄버거로 숨기지 않는다.
- 방문 링크 색 변화는 유지하되 접근성 대비를 확인한다.
- 오래된 사진에는 대체 텍스트와 촬영연도를 기록한다.
