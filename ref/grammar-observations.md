# 오래된 아마추어 수상스포츠 웹사이트의 문법 — 초안

이 문서는 최종 디자인 명세가 아니라, 현재까지 반복해서 발견된 요소를 기록한 1차 관찰 노트다.

## 1. 정체성 영역

- 직접 그린 듯한 단체 로고 또는 원형 엠블럼
- 창립연도, 지역명, 종목명이 로고 가까이에 표시됨
- 한국어·영어 또는 현지어·영어 명칭이 함께 사용됨
- 거창한 브랜드 문구보다 `환영합니다`, `우리 클럽은…` 같은 직접적인 소개문
- 회장·웹마스터·대표 연락처가 눈에 잘 띄는 곳에 노출됨

## 2. 헤더와 메뉴

- 로고 왼쪽, 가로 메뉴 오른쪽 구성
- 또는 좁은 왼쪽 세로 메뉴와 넓은 본문 구성
- `클럽 소개 / 가입 / 활동 / 일정 / 사진 / 자료실 / 연락처`가 기본 골격
- 협회형 사이트는 지역지부·위원회·규정·자료실이 다단 드롭다운으로 크게 확장됨
- 로그인, 회원가입, 회비 납부가 공공 메뉴와 같은 위계에 놓임

## 3. 첫 화면의 다단 구조

- 한 개의 강한 히어로보다 여러 작은 정보 블록이 동시에 보임
- 보통 2–4열: 공지, 최근 게시글, 다음 행사, 날씨·수위, 바로가기
- 카드의 높이나 문장 길이가 완전히 맞지 않아도 그대로 배치됨
- 굵은 테두리, 단색 제목 바, 회색 구분선으로 모듈 경계를 만듦
- 빈 공간보다 정보 밀도를 선호함

## 4. 반복되는 콘텐츠 모듈

- 공지사항과 최신 소식
- 다음 행사 또는 연간 행사표
- 월간 달력
- 활동 사진 또는 작은 썸네일 그리드
- 회원회보·클럽지 PDF
- 가입 안내와 회비
- 초보자 교육·강습 일정
- 장비 대여·보트 보관·선석 정보
- 날씨, 수온, 풍향, 수위와 같은 현장 상태
- 방명록 또는 자유게시판
- 중고장터·사고팔기
- 후원사 로고
- 운영진·위원회 명단

## 5. 이미지 사용법

- 전문 촬영 이미지보다 회원이 직접 찍은 행사 사진
- 비율과 해상도가 서로 다른 사진을 함께 사용
- 사진 아래에 짧거나 매우 구체적인 설명문
- 오래된 행사 사진과 최근 사진이 같은 위계로 공존
- 슬라이더보다 단순한 썸네일 링크나 본문 삽입 이미지가 더 어울림
- 배, 패들, 구명조끼, 클럽하우스, 선착장, 호수, 단체사진이 핵심 소재

## 6. 타이포그래피와 색

- 기본 시스템 산세리프 또는 오래된 웹 기본 글꼴
- 본문 12–16px, 조밀한 줄간격
- 파랑·남색·물빛·빨강을 제목 바와 테두리에 제한적으로 사용
- 흰색 또는 옅은 회색 배경
- 링크는 명확한 파랑 또는 밑줄
- 제목의 대문자 사용과 서로 다른 글자 크기가 다소 불규칙함

## 7. 시간성과 기록

- 각 글에 날짜가 강하게 표시됨
- `마지막 업데이트`, `온라인 시작일`, 저작권 연도가 보임
- 뉴스 아카이브가 연도별로 계속 쌓임
- 지난 행사도 삭제하지 않고 클럽의 역사로 남김
- 현재 공지와 10년 이상 된 사진·문서가 자연스럽게 같은 페이지에 공존

## 8. 의도적으로 살릴 수 있는 불완전함

- 열마다 카드 높이가 다름
- 제목이 줄바꿈되거나 약간 반복됨
- 작은 아이콘과 저해상도 로고
- 일정하지 않은 사진 크기
- PDF, 이메일, 외부 날씨 페이지로 바로 연결되는 링크
- 다소 긴 소개문과 실무적인 연락 문구

단, 실제 구현에서는 깨진 문자, 접근성 문제, 보안 문제, 모바일 사용 불가를 그대로 재현하지 않는다. 시각적 불완전함만 선택적으로 차용한다.

## 9. 이 프로젝트에 적합한 잠정 조합

- KARL의 밀도 높은 협회형 메뉴와 3–4열 홈 대시보드
- Esrum Sø의 날씨·수온·풍향 상태 블록
- Sørup Havns Bådelav의 회원회보·사진·생활형 행사 기록
- KSV Lok Riesa의 작은 인라인 사진과 마지막 업데이트 문구
- Aquaklubben의 왼쪽 메뉴와 짧은 뉴스 목록
- Oxelösunds 1997 페이지의 링크 디렉터리와 초기 웹 분위기

이 조합을 사용하면 ‘실제로 오랫동안 운영된 한국의 아마추어 카누 협회 홈페이지’처럼 보이면서도, 카누라는 테마를 첫 화면에서 명확하게 전달할 수 있다.

## 10. 개인·지역·소형 상점까지 넓힌 뒤 추가된 문법

- 개인 소개, 취미, 가족 이야기, 지역 정보와 상점이 엄격히 분리되지 않는다.
- 방문자 카운터, 사이트 개설일, 마지막 업데이트와 웹마스터 이름이 작은 상태 줄로 표시된다.
- 방명록은 후기 기능이 아니라 운영자와 방문객이 서로 아는 공동체 공간으로 쓰인다.
- 외딴 지역 사이트는 행사 외에도 날씨, 교통, 재활용, 해변, 주차와 새 주민 안내를 제공한다.
- 소형 취미 상점은 문자 주문, 현장 수령, 현금·계좌 결제, 직접 작성한 할인 규칙을 숨기지 않는다.
- 링크 디렉터리와 연도별 아카이브가 추천 알고리즘 대신 탐색 구조를 만든다.
- 운영자의 말투와 사연이 곧 브랜드이며, 완벽한 기업 문장보다 구체적이고 실무적인 문장이 많다.
- 깨진 문자나 죽은 링크 자체는 재현하지 않되, 서로 다른 이미지 크기와 오래된 PDF·사진첩은 시간의 층으로 활용할 수 있다.
